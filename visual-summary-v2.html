在线模式 (Hybrid / Cloud-only)

检测到外网 + 至少 1 个云端 API 可达

  • 首选 云端 LLM（最佳质量）
  • 失败 1 次（5xx/超时/网络错误）→ 切本地
  • embedding 同样优先云端，降级到本地 nomic-embed
  • 可设置 HERMES_LLM_MODE=cloud-only 强制只用云端

离线模式 (Local-only)

无外网 / API Key 缺失 / 所有云 API 探测失败

  • 只走 本地 llama-server
  • 自动降级响应：max_tokens=1024、prefer_concise=true
  • 禁用工具：web-search / http-fetch
  • 可设置 HERMES_LLM_MODE=local-only 强制只用本地

启动流程时间线

// BOOT.SEQUENCE.v2

T+0s

插入移动硬盘 + 双击 start.bat

脚本自动解析 U 盘根目录（不依赖盘符），检测 Podman/Docker。

T+5-90s (首次) / T+2s (后续)

镜像加载

首次 gunzip -c image.tar.gz | docker load。镜像含 Mavis + llama.cpp + 所有 Python 依赖。

T+95s (首次) / T+5s (后续)

容器启动 + 网络检测

entrypoint.sh 跑起来，llama-router.sh 探测外网和云端 API，输出 HERMES_NETWORK / HERMES_LLM_MODE。

T+100-150s

本地 LLM 预热

如果 /data/models/*.gguf 存在，llama-supervisor.sh 启动 llama-server，加载模型到内存，等待 /health 200。

T+150s

Mavis 就绪

Web UI @ http://localhost:7860。在线时调云端 GPT-4o / Claude，离线时调本地 Qwen2.5-3B，用户无感切换。

核心命令速查

// QUICK.REFERENCE

首次配置（装机）

# 1. 构建 Docker 镜像（含 Mavis + llama.cpp）
docker buildx build --platform linux/amd64 \
    --output type=docker,dest=docker/image.tar \
    -t portable-hermes:latest .

# 2. 压缩保存
docker save portable-hermes:latest | gzip -9 > docker/image.tar.gz

# 3. 准备 .env
cp .env.example .env
# 编辑填入 OPENAI_API_KEY 等

# 4. 下载本地模型（首次必跑，需要网络）
./scripts/setup-model.sh default

日常使用（任意机器）

# 启动
./scripts/start.sh                  # Mac/Linux
scripts\start.bat                   # Windows

# 切换本地模型档位
./scripts/switch-model.sh powerful

# 强制模式（写到 .env 持久化）
HERMES_LLM_MODE=local-only   # 只用本地
HERMES_LLM_MODE=cloud-only    # 只用云端
HERMES_LLM_MODE=hybrid        # 默认

# 启用 GPU（需要 nvidia-container-toolkit）
LLAMA_USE_GPU=1 ./scripts/start.sh

# 拉取新镜像
./scripts/update.sh https://your-server.com/hermes-latest.tar.gz

容器内调试

# 查看本地 LLM 状态
docker exec hermes-portable llama-supervisor.sh status

# 重启本地 LLM（切换模型后）
docker exec hermes-portable llama-supervisor.sh restart

# 查看本地 LLM 日志
docker exec hermes-portable tail -f /opt/llama/logs/llama-server.log

# 直接 curl 本地 LLM
curl http://localhost:8080/v1/chat/completions \
    -H "Content-Type: application/json" \
    -d '{"model":"qwen2.5-3b","messages":[{"role":"user","content":"hi"}]}'
