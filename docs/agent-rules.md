# Agent 操作边界规则（2026-07-13 总结）

> 来自哥哥用 workbuddy 踩坑后的经验总结。Ikaros 必须遵守。

## 规则 R1-DRY：优先复用现成方案
写代码时，先搜有没有现成的、成熟的轮子，不要自己造。

## 规则 R2-OFFICIAL：官方文档优先
从云端拉取的项目组件，做环境搭配、运行、写调用代码时：
1. 优先参考官方文档和使用方法
2. 实在没有官方文档，才看 `--help`
3. 最后才去读源码或推测实现逻辑

## 规则 R3-BANDWIDTH：满速下载
下载东西前：
1. 先测当前网络上限带宽
2. 选最优下载通道
3. 确保满速下载

## 规则 R4-KISS：保持简单
调试时：
1. 尽可能减少嵌套
2. 有把握时用原生代码，不要搞复杂
3. 安全场景才加额外防护层，别过度设计
