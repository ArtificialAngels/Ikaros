| `bin/` | ✓ | 启动器集合(CRLF!) |
| `bridge/` | ✓ | FastAPI 后端 |
| `config/` | ✓ | yaml 配置 |

| `docs/` | ✓ | 用户文档 |
| `hermes/` | ✓ | Python 桥接层 |
| `hermes-agent/` | ✓ | 上游干净副本 |
| `hermes-web-ui/` | ✓ | 上游干净副本 |

| `.env` | ✗ | 本地环境变量(可能含 API key) |

## 几个新手最容易搞混的路径

- **`bin\`** 是**项目自己的**启动器(CRLF 行尾!)。`runtime\` 是 llama.cpp + DLL,
  `portable-python\` 是嵌入式 Python——两个都不是 git 跟踪,首次 `git clone` 后
  要跑 `bin\setup-portable.bat` 下载。
- **`hermes-agent\`** 和 **`hermes-web-ui\`** 是从 GitHub 同步的**上游干净副本**,
  改任何东西都会让下一次 `git pull` 冲突。它们是只读的(虽然 git 不强制)。
  我们的二次开发都放在 `modules\` 下。
- **`.hermes-root`** 不是配置文件,是 `hermes-root.py` 第一次启动时
  原子写入的 HERMES_ROOT 缓存(加速后续启动)。删掉它会触发一次盘符扫描。
