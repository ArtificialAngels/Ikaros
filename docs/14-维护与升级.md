# 14 — 维护与升级

## 升级 portable-python

便携 Python 一般不需要升级。如果必须升级：

1. 备份 `portable-python/Lib/site-packages/`（你安装的 pip 包）
2. 下载新版 embeddable Python，替换 `portable-python/`
3. 把 `python._pth` 改成原来的配置（取消 `import site` 注释）
4. 重新安装依赖：`portable-python\python.exe -m pip install -r requirements.txt`

## 升级 llama.cpp（runtime/）

1. 从 [llama.cpp releases](https://github.com/ggml-org/llama.cpp/releases) 下载最新 Windows 包
2. 解压替换 `runtime/` 目录
3. 注意保留 `libomp140.x86_64.dll`（如果有）

## 升级 Hermes Agent 代码

```bat
:: 如果在 git 仓库里
git pull

:: 否则重新下载解压覆盖
```

## 更新 Python 依赖

```bat
portable-python\python.exe -m pip install -r requirements.txt --upgrade
```

## 添加新模型

1. 下载 GGUF 模型文件
2. 放到 `data/models/` 目录
3. 运行 `launcher.bat` 自动识别

模型推荐（按性能排序）：

| 模型 | 大小 | 显存需求 | 适用 |
|---|---|---|---|
| Qwen3-8B-Q4_K_M | ~5GB | 8GB VRAM | 通用对话 |
| Qwen2.5-7B-Q4_K_M | ~4.4GB | 6GB VRAM | 通用对话 |
| Qwen2.5-3B-Q4_K_M | ~2GB | 4GB VRAM | 低配/快速 |
| Qwen2.5-1.5B-Q4_K_M | ~1GB | 2GB VRAM | 极低配 |

## 备份什么

| 必须备份 | 重要 | 备份价值不大 |
|---|---|---|
| `hermes/data/memory/`（长期记忆） | `data/models/`（几十 GB，看容量） | `hermes/data/cache/` |
| `hermes/data/knowledge/`（知识库索引） | `hermes/data/skills/`（自定义技能） | `hermes/data/logs/` |
| `config/hermes.yaml`（主配置） | `config/models.yaml`（模型配置） | `__pycache__/` |
| `.env`（API 密钥） | | |

## 完全重置

1. 关闭 Hermes 和 LLM 服务
2. 备份你想保留的数据（见上表）
3. 删除 `hermes/data/`（或仅删除 `hermes/data/cache/` `hermes/data/logs/`）
4. 重新运行 → Agent 会重新初始化
