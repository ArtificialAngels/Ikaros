# 14 — 维护与升级

## 升级便携运行时(`portable-python/` + `runtime/`)

```bat
bin\setup-portable.bat
```

会自动用 aria2c 多线程下载:
- `portable-python/` — 嵌入式 Python 3.12.10
- `runtime/` — llama.cpp Windows 二进制 + DLL
- `runtime/cuda/12.4/` — CUDA 12.4 运行时(默认)
- `runtime/node23/` — Node.js 23.11.1

下载完成后**第一次启动前** 跑一次 `bin\hermes-firstrun.bat` 验证。

## 升级 llama.cpp(runtime 内的二进制)

```bat
:: 1. 备份旧版本
rename runtime runtime.bak.20260613

:: 2. 用 setup-portable.bat 拉最新(包含上游 llama.cpp 预编译 Windows 包)
bin\setup-portable.bat

:: 3. 如果新版 API 有 breaking,看 AGENTS.md §10 历史章节 + bin\fix-eol.py 跑一下
```

或者直接从 [llama.cpp releases](https://github.com/ggml-org/llama.cpp/releases) 下 Windows zip 解压替换 `runtime/`。注意保留 `libomp140.x86_64.dll`(如果有)。

## 升级 Hermes 框架代码

```bat
:: 在 git 仓库里
git pull

:: 然后跑一次 CRLF 归一化
portable-python\python.exe bin\fix-eol.py --all
```

## 更新 Python 依赖

```bat
portable-python\python.exe -m pip install -r requirements.txt --upgrade
```

## 升级上游 hermes-agent(NousResearch)

```bat
:: 1. 备份当前干净副本(万一新版炸了)
rename hermes-agent hermes-agent.bak.20260613

:: 2. 重新 clone
git clone --depth=1 https://github.com/NousResearch/hermes-agent.git hermes-agent

:: 3. 如果我们写了对上游的 adapter / sitecustomize(在 bridge/),确认还能用
dir bridge
```

## 升级上游 hermes-web-ui(EKKOLearnAI)

我们不再 clone `.\hermes-web-ui\` 作为 dev 源 (2026-06-15a 已退役)
—— npm 全局包是唯一路径。

```bat
cd runtime\node23
:: 升到最新版
npm install -g hermes-web-ui@latest
:: 或锁定到某个版本
:: npm install -g hermes-web-ui@0.6.14

:: 重启 webui 生效
bin\hermes-stop.bat
bin\hermes-all.bat
```

如果客户端适配(我们的 `modules/webui/start.ps1` 注入的 env vars)有变化,
查 `modules\webui\start.ps1` 和 `bridge\server.py`。

## 添加新模型

1. 下载 GGUF 模型文件(从 HuggingFace / ModelScope / hf-mirror)
2. 放到 `data\models/` 目录
3. 重启 `bin\hermes-all.bat`,router 模式自动发现
4. (可选)编辑 `data\models\router-preset.ini` 给它单独配 NGL / ctx

### 推荐模型(按性能排序)

| 模型 | 大小 | 显存需求 | 适用 |
|---|---|---|---|
| Qwen2.5-1.5B-Instruct-Q4_K_M | ~1 GB | 2 GB VRAM | 极低配 / 快速 |
| Qwen2.5-3B-Instruct-Q4_K_M | ~2 GB | 4 GB VRAM | 低配 / 快速 |
| Qwen2.5-7B-Instruct-Q4_K_M | ~4.4 GB | 6 GB VRAM | 通用对话 |
| Llama-3.1-8B-Instruct-Q4_K_M | ~4.7 GB | 6 GB VRAM | 通用对话 |
| Qwen3-30B-A3B (MoE) | ~18 GB | 8 GB VRAM(部分 offload) | 强推理 |

### 模型 NGL 自动 / 手动

- **自动**:`bin\hermes-all.bat` 启动时根据 VRAM 自动算每个模型的 NGL。
- **手动**:`data\models\router-preset.ini` 给特定模型写死 NGL / ctx / temperature。

## 备份什么

| 必须备份 | 重要 | 备份价值不大 |
|---|---|---|
| `.env`(API 密钥) | `data\models\`(几十 GB,看容量) | `__pycache__/` |
| `data\memory\`(长期记忆) | `data\skills\`(用户安装 skill) | `data\logs\` |
| `data\knowledge\`(KB 索引) | `data\hermes-agent\`(webui 状态/会话) | `.opencode/tmp/` |
| `data\webui\`(webui 数据库) | `data\kanban\` / `data\crons\` / `data\sessions\` | `.hermes-root` |
| `config\hermes.yaml` | | `portable-python\`(可重下) |
| `data\models\router-preset.ini` | | `runtime\`(可重下) |

## 完全重置

1. **关闭 Hermes 和 LLM 服务**:`bin\hermes-stop.bat`
2. **备份**你想保留的数据(见上表)
3. **删除运行时数据**:
   ```bat
   rd /S /Q data\memory
   rd /S /Q data\knowledge
   rd /S /Q data\logs
   rd /S /Q data\hermes-agent
   rd /S /Q data\webui
   rd /S /Q data\kanban
   rd /S /Q data\crons
   rd /S /Q data\sessions
   REM 不要删 data\models\(模型权重)
   ```
4. **重新启动**:`bin\hermes-all.bat` — 自动重新初始化

## 移动到别的 U 盘

```bat
:: 1. 关闭所有
bin\hermes-stop.bat

:: 2. 整个项目文件夹拷到新 U 盘(随便盘符)

:: 3. 删除 HERMES_ROOT 缓存(强制重新解析路径)
del .hermes-root

:: 4. 启动
bin\hermes-all.bat
```

> `bin\hermes-root.py` 会扫描所有盘符找 `Hermes Agent/portable-python/python.exe`,自动确定新根路径。

## CRLF 行尾维护

```bat
:: 检查哪些 .bat / .ps1 行尾不对
portable-python\python.exe bin\fix-eol.py --check

:: 自动归一化
portable-python\python.exe bin\fix-eol.py --all

:: git hooks(已注册 .githooks/pre-commit)会阻止 LF-only .bat 提交
bin\install-git-hooks.bat
```

## 升级 Git hooks

`.githooks/pre-commit` 是 **版本化** 的(在 git 里跟踪),`bin\install-git-hooks.bat` 一次性把它指向 `core.hooksPath`。`git pull` 之后 hook 自动更新,不需要重装。
