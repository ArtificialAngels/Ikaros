# 15 — 故障排查与救命命令

## 出问题去哪查(快速诊断表)

| 现象 | 第一看 | 备选 |
|------|--------|------|
| 浏览器打不开 | `bin\hermes-health.ps1` 三层探测 | 看 `data\logs\` 最新日志 |
| Web UI (:8648) 空白 | F12 浏览器控制台 | `curl http://localhost:8648/api/version` |
| Bridge (:7860) 不响应 | `curl http://localhost:7860/health` | `data\logs\bootstrap.log` |
| LLM 服务 (:8080) 起不来 | `bin\hermes-model-run.bat` 实时日志 | 手动跑 `runtime\llama-server.exe -m data\models\xxx.gguf` |
| 对话不响应 / 流式中断 | `bin\hermes-model-run.bat` | `curl http://localhost:8080/v1/models` |
| 云端 LLM 失败 | `.env` 文件 API Key | 检查网络 / 代理设置 |
| 模型找不到 | `data\models\` 下是否有 .gguf 文件 | `bin\hermes-models.py list` |
| 显存不足(OOM) | 选小模型(Qwen2.5-3B) | `data\models\router-preset.ini` 调小 `n_gpu_layers`,35B 默认 16 层 GPU + CPU offload |
| GPU 加速不生效 | NVIDIA 驱动版本 | `bin\gpu-detect.bat` |
| API 密钥泄漏 | `git log --all -- .env` | 检查是否被误提交 |
| Git commit 被阻止 | `portable-python\python.exe bin\fix-eol.py --all` | 检查 .bat 行尾 |
| Logs page 报 `spawn E:\Hermes Agent\bin ENOENT` | env loader 没 pin `HERMES_AGENT_CLI_PYTHON` | 详见 `AGENTS.md §0` (env-loader gotcha) |
| Path resolution 异常 | `bin\hermes-root.bat resolve` | `bin\hermes-root.bat scan` 扫所有盘符 |

## 三层健康检查的"OK"标准

```bat
bin\hermes-health.ps1
```

依次探测:

1. **TCP 端口** — `:8080` / `:7860` / `:8648` 是否监听
2. **HTTP API** — `GET /v1/models` 是否返回 JSON(`llama-server`)
3. **端到端推理** — `POST /v1/chat/completions` 一句话测试是否返回内容

任何一个挂了就告诉你哪个模块出问题。

## 救命命令

```bat
:: === 启动 / 停止 ===
bin\hermes-all.bat                 :: 启动全部
bin\hermes-stop.bat                :: 停止全部
bin\hermes-firstrun.bat            :: 首次运行 / GPU 检测
bin\hermes-health.ps1              :: 三层 liveness 探测

:: === 调试 ===
bin\hermes-model-run.bat           :: 实时 LLM 日志
bin\hermes-console.bat             :: 交互式 shell
bin\hermes-root.bat resolve        :: 打印 HERMES_ROOT
bin\hermes-root.bat verify         :: 验证关键标记物
bin\hermes-models.py list          :: 列出所有模型

:: === 强制结束进程 ===
taskkill /F /IM llama-server.exe
taskkill /F /IM python.exe
taskkill /F /IM node.exe

:: === 清日志 ===
del /Q data\logs\*.log

:: === 重置 agent 数据(保留模型) ===
rd /S /Q data\memory
rd /S /Q data\knowledge
rd /S /Q data\logs

:: === 手动跑 LLM(用于调试) ===
runtime\llama-server.exe -m data\models\Qwen2.5-3B-Instruct-Q4_K_M.gguf --port 8080 -ngl 0

:: === 测试端口 ===
curl http://localhost:8080/v1/models
curl http://localhost:7860/health
curl http://localhost:8648/api/version

:: === 看端口占用 ===
netstat -ano | findstr :8080
netstat -ano | findstr :7860
netstat -ano | findstr :8648

:: === CRLF 行尾检查(commit 前必跑) ===
portable-python\python.exe bin\fix-eol.py --check
```

## 常见问题快速修复

### Q: "No module named 'xxx'"

```bat
portable-python\python.exe -m pip install xxx
```

### Q: llama-server.exe 闪退

```bat
:: 手动运行看报错
runtime\llama-server.exe -m data\models\Qwen2.5-3B-Instruct-Q4_K_M.gguf --port 8080

:: 大概率是 VRAM 不够,改用更小的模型,或者 -ngl 0 全 CPU
runtime\llama-server.exe -m data\models\Qwen2.5-3B-Instruct-Q4_K_M.gguf --port 8080 -ngl 0
```

### Q: Web UI 页面空白

按 F12 打开浏览器控制台看 JS 报错。检查 `modules\webui\start.ps1` 的环境变量是否正确设置。

### Q: 云端 API 调用超时

检查 `.env` 中 API Key 有效性。检查代理设置(Clash / V2Ray 是否在跑)。看 `config\hermes.yaml` 的 `network.proxy_address`。

### Q: 浏览器没自动打开

`bin\hermes-all.bat` 启动 webui 后会 `start http://localhost:8648/`,失败就手动打开。

### Q: "Port already in use"

```bat
netstat -ano | findstr :8648
taskkill /F /PID <PID>
```

或者修改 `modules\webui\module.json` 的 `port` 字段。

### Q: 模型加载很慢

第一次加载某模型几秒到几十秒(取决于磁盘 IO + 模型大小),后续走 LRU 缓存是毫秒级。看 `bin\hermes-model-run.bat` 的 "model loaded" 日志。

### Q: VRAM 占用超限

`data\models\router-preset.ini` 给大模型调低 `n_gpu_layers`:

```ini
[Qwen3-30B-A3B-Q4_K_M.gguf]
n_gpu_layers = 8       ;; 8GB 显卡放不下全 offload
ctx_size = 2048
```

### Q: git commit 被 pre-commit 阻止

```
ERROR: .bat file bin\xxx.bat has LF line endings, must be CRLF
```

解决:`portable-python\python.exe bin\fix-eol.py --all`

### Q: 隐私泄漏怎么挽回

```bat
:: 看看 .env 是不是误提交了
git log --all -- .env

:: 如果是,从历史里彻底删除(重写历史,如果有 push 到远程则需要 force push)
git filter-branch --force --index-filter \
  "git rm --cached --ignore-unmatch .env" \
  --prune-empty -- --all

:: 然后立刻换新的 API Key
```

如果已经 push 到公开仓库,**API Key 必须作废重发**,filter-branch 不能删除远程历史。

## 完整重置(救命选项)

```bat
:: 1. 停止
bin\hermes-stop.bat

:: 2. 删运行时数据(保留模型)
rd /S /Q data\memory data\knowledge data\logs data\hermes-agent data\webui data\kanban data\crons data\sessions

:: 3. 删 HERMES_ROOT 缓存(强制重新解析路径)
del .hermes-root

:: 4. 重新启动
bin\hermes-all.bat
```

## 完整卸载(要从 U 盘删掉)

直接 `rmdir /S /Q "E:\Hermes Agent"`,但建议先备份 `.env` 和 `data\memory\`。
