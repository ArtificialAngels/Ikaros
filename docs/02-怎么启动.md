# 02 — 怎么启动

## 推荐：用启动器（零门槛）

```
双击 launcher.bat
```

图形化模型选择器（Tkinter GUI），功能：

- 一键扫描本地模型（GGUF 文件）
- 自动检测 GPU（NVIDIA / AMD / CPU）
- 自动配置 llama.cpp 参数（GPU layers、context window）
- 启动 LLM 服务 → 自动打开 Web UI

启动后默认在浏览器打开 Chat Studio（`http://localhost:7860/chat`）。

## 备选：命令行直接跑

### 一键启动全部
```bat
bin\hermes-all.bat
```
自动启动 LLM 服务 + Web UI。

### 仅 Web UI
```bat
bin\hermes-web.bat
```
需要 LLM 服务已在 `http://localhost:8080` 运行。

### CLI 对话
```bat
bin\hermes.bat
```
直接进入交互式命令行。

### 仅 LLM 服务
```bat
bin\hermes-all.bat (用 llama-server router 模式,扫 data\models 自动发现所有 GGUF)
```
启动 llama-server，可被任何 OpenAI 客户端调用。

### 停止所有
```bat
bin\hermes-stop.bat
```

## 诊断

```bat
bin\hermes-doctor.bat
```
扫描项目检查常见问题，输出诊断报告。

## 首次运行

```bat
bin\hermes-firstrun.bat
```
检测 GPU、下载缺失的运行时依赖、报告可用的后端。

## 配置文件解读（`config/hermes.yaml`）

```yaml
llm:
  router:
    strategy: fallback_chain       # 失败自动切换
    primary: cloud                 # 首选云端
    fallback_order: [cloud, local]

  cloud:                           # 云端 LLM 列表
    - name: openai
      provider: openai
      base_url: https://api.openai.com/v1
      models:
        default: gpt-4o
        fast: gpt-4o-mini

  local:                           # 本地 LLM
    provider: openai               # llama.cpp 提供 OpenAI 兼容接口
    base_url: http://127.0.0.1:8080/v1
    models:
      default: qwen2.5-3b-instruct
```

**关键参数**：
- `strategy: fallback_chain` — 云端挂了自动切本地
- `primary: cloud` — 有网优先用云端的强模型
- `base_url` — 本地 LLM 默认端口 8080
