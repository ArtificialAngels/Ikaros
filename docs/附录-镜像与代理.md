# 附录 — 镜像与代理配置

> 你在 `docs/` 目录。

## 配置位置

镜像和代理配置位于 `config/hermes.yaml` 的 `network` 段：

```yaml
network:
  proxy_address: ""                  # 代理地址，如 http://127.0.0.1:7890
  mirror_pypi: false                 # PyPI 镜像开关
  mirror_huggingface: false          # HuggingFace 镜像开关
  mirror_git: false                  # GitHub 镜像开关
  pypi_mirror: aliyun                # aliyun | tsinghua | ustc
  hf_mirror: hf-mirror               # hf-mirror
  git_mirror: gh-proxy               # gh-proxy | gitclone | fastgit
```

## 推荐配置（国内慢网用户）

```yaml
network:
  proxy_address: "http://127.0.0.1:7890"
  mirror_pypi: true
  mirror_huggingface: true
  mirror_git: true
  pypi_mirror: aliyun
  hf_mirror: hf-mirror
  git_mirror: gh-proxy
```

## 可用镜像站点

### PyPI 镜像
| 镜像 | URL |
|---|---|
| 阿里云 | `https://mirrors.aliyun.com/pypi/simple/` |
| 清华大学 | `https://pypi.tuna.tsinghua.edu.cn/simple/` |
| 中科大 | `https://pypi.mirrors.ustc.edu.cn/simple/` |

### HuggingFace 镜像
| 镜像 | URL |
|---|---|
| HF-Mirror | `https://hf-mirror.com` |

### Git 镜像
| 镜像 | URL |
|---|---|
| gh-proxy | `https://gh-proxy.com/` |
| gitclone | `https://gitclone.com/github.com/` |
| fastgit | `https://hub.fastgit.xyz/` |

## 环境变量方式

如果不修改 yaml，也可以通过环境变量设置：

```bat
set HERMES_PROXY=http://127.0.0.1:7890
set HERMES_MIRROR_PYPI=true
set HERMES_MIRROR_HF=true
set HERMES_MIRROR_GIT=true
```

## 诊断

```bat
bin\hermes-doctor.bat
```

会报告镜像状态和网络连通性。
