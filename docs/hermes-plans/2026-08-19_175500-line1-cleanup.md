## 🚨 Risk / Gotcha

- **R1：删错物导致运行崩溃**——`apps/neko` 在 dsh overlay 里仍有引用？必须 Task 1.1 先扫干净。
- **R2：CHANGELOG 保留价值**——历史 backup 删了 git 还能看，但 tmp/ 里的 .db 备份删了真没了。
- **R3：tmp/ 不能一刀切**——里面有 2026-08-14 合并的备份数据，删了不能重建。
- **R4：删 .bak 撞名**——某些合法文件可能以 .bak 结尾（虽罕见），抽样 review 必要。
- **R5：__pycache__ 在某些 .gitignore 不规范的项目里被 track**——必须 `--cached` 双重删。
