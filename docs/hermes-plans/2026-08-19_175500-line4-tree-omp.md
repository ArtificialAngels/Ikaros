### Task 4.5: 降级路由

        """Routes through active base, fallback if failed"""

## 🚨 Risk / Gotcha

- **R1：omp TUI 无 HTTP**——健康检测只能用进程探活，不能用 `/healthz` 模式。
- **R2：降级时上下文丢失**——memory_v5 必须有"会话上下文持久化"才能切换无感。可能要先做线 2 的相关改造。
- **R3：omp go-deepseek 通道限流**——DeepSeek API 共享配额，dsh + omp 并发可能撞限流。需要协调。
- **R4：对话树增强无限可能**——按哥哥点的顺序做，不一次铺开。
- **R5：双基座对用户透明**——不能因为降级导致用户看到"陌生"界面。要平滑。
