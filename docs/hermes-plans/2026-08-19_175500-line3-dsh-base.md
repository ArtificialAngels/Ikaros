### Task 3.3: 启动器 v1 实现

**Objective:** 实现最小可用启动器。

**Step 1:** `bin/ikaros`（bash）：
```bash
#!/usr/bin/env bash
# ikaros launcher v1
set -e
IKAROS_ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
export IKAROS_ROOT
source "$IKAROS_ROOT/bin/ikaros-env.sh"

case "${1:-help}" in
  web)      exec "$IKAROS_ROOT/bin/start-dsh-ikaros.bat" web ;;
  tree)     exec python "$IKAROS_ROOT/core/conversation-tree/server.py" --port 48920 ;;
  embed)    # 启动 embedding 服务
    ;;
  all)      # 全栈
    ;;
  doctor)   # 诊断
    ;;
  *)        echo "Usage: ikaros {web|tree|embed|all|doctor}" ;;
esac
```

## 🚨 Risk / Gotcha

- **R1：启动器跨平台兼容坑**——cmd 编码（GBK 不能有 UTF-8）、PowerShell 引号转义、bash MSYS 路径——每个 shell 单独测。
- **R2：动 bin/ 路径会破现有用户**——README 改了，但用户可能照搬老命令。要保留 thin wrapper。
- **R3：组件插件接口过度设计**——避免加"YAGNI"字段。每个字段必须有真实消费者。
- **R4：dsh overlay 与组件 plugin 重复**——`ikaros-dsh/` 是 dsh 专属，组件 plugin 是更宽的概念。两者并存而非重复。
- **R5：dsh 版本升级**——dsh 是 npm 包，升级可能破坏 overlay。每次升级要回归测试。
