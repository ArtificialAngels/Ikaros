# 01 — 这是什么

## 是什么

- **Hermes Agent** 是一个"赛博游民数字管家" —— 装在 U 盘里,插到任何 Windows 电脑就能跑的 AI 助手。
- 核心理念:**零系统依赖、自包含**。不需要装系统 Python,不需要装 Node,不需要联网(如果只用本地模型)。
- 功能涵盖:AI 对话、长期记忆、知识库检索、看板 / 定时任务、自定义技能、多 Profile、文件浏览器、群聊、Web 终端。

## 能用它做什么

### 本地 LLM(断网也能用)

- **llama.cpp router 模式** —— 单进程扫 `data\models\` 注册所有 GGUF,Web UI 下拉菜单切模型,无需重启。
- **Per-model NGL / ctx** —— 在 `data\models\router-preset.ini` 给每个模型单独配(35B 在 8GB 显卡上 16 层 GPU + CPU offload)。
- **多版本 CUDA 自适应** —— `runtime/cuda/{11.8, 12.4, 13.0}/` 按 NVIDIA 驱动自动选。

### 云端 LLM(fallback)

- OpenAI / Anthropic / OpenRouter / MiniMax
- 写 `.env` 填 API Key 即可,failure 自动切本地

### 模块化服务

- `modules/{env_bootstrap, llm_engine, bridge, webui, model_manager, supervisor}` —— 每个模块自描述(`module.json` + `start.ps1` + `health.ps1`)
- `bin\hermes-supervisor.py` 拓扑排序,按依赖启动,失败回滚
- 新服务 = 新建目录 + 写 `module.json`,supervisor 自动接入

### Web UI 全功能(端口 8648,主入口)

- AI 实时流式聊天、多会话管理、Markdown / LaTeX / 代码高亮
- 用量分析(Token / 费用 / 30 天趋势)
- 定时任务(Cron 表达式,UI 创建)
- 模型管理(自动发现 + Provider + OAuth 登录)
- 多 Profile(配置隔离 / 导入 / 导出 / 克隆)
- 文件浏览器(本地 / Docker / SSH / Singularity)
- 群聊(多 Agent 房间 + @mention 路由)
- 技能管理 + 记忆浏览 + 日志查看 + Web 终端
- 8 平台渠道配置(Telegram / Discord / Slack / WhatsApp / Matrix / 飞书 / 微信 / 企业微信)

### U 盘便携

- `bin\hermes-root.py` 自动解析项目根路径(`E:\` / `F:\` / `G:\` 都行),无需修改配置
- 自带便携 Python 3.12.10 + Node 23.11.1 + llama.cpp + CUDA 运行时
- 拷整个文件夹到任何 Windows 电脑就能跑

## 用户协议

- 仅作 AI 技术学习用途
- Hermes Agent 只提供**运行环境**,模型权重请自行从 HuggingFace / ModelScope 下载
- 严禁用于违法违规内容(政治敏感 / 暴力色情 / 侵犯他人权益等)
- 自负其责

> 简而言之:**工具是中性的,生成的内容你自己负责**。

## 适用场景

- **U 盘携带**,多电脑切换使用(办公 / 家庭 / 网吧)
- **断网环境**下的本地 AI 助手
- 需要**长期记忆**的持续对话
- 个人**知识库管理**(Markdown / TXT / PDF)
- AI **技能开发和测试**(放 `.py` 到 `data\skills\` 即可)
- **多模型 router** 实验场景(同进程加载多个 GGUF)

## 不适用场景

- 需要 GPU 集群的训练 / 微调(本项目只做推理)
- macOS / Linux 原生部署(本项目为 Windows 优先;Linux 需手动跑 `hermes-agent\` 自己的 docker-compose)
- 多人协作 + 多租户(本项目是个人 / 团队本地使用)
