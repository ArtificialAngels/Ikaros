# 01 — 这是什么

## 是什么

- **Hermes Agent** 是一个"赛博游民数字管家"——装在 U 盘里，插到任何 Windows 电脑就能跑的 AI 助手。
- 核心理念：**零依赖、自包含**。不需要装 Python，不需要联网（如果只用本地模型）。
- 功能涵盖：AI 对话、长期记忆、知识库检索、自定义技能、模型管理。

## 用户协议

- 仅作 AI 技术学习用途
- Hermes Agent 只提供**运行环境**，模型权重请自行下载
- 严禁用于违法违规内容（政治敏感、暴力色情、侵犯他人权益等）
- 自负其责

> 简而言之：工具是中性的，生成的内容你自己负责。

## 能用它做什么

- **AI 对话**：云端 LLM（GPT-4o / Claude / OpenRouter）+ 本地模型（Qwen2.5 GGUF）
- **长期记忆**：自动记住对话要点，支持标签检索和回看
- **知识库**：导入文档（Markdown / TXT / PDF），向量检索 + RAG
- **自定义技能**：在 `hermes/data/skills/` 下写 Python 脚本扩展能力
- **模型管理**：图形化切换本地模型、检测 GPU、自动配置
- **离线可用**：纯本地模式无需联网，全部跑在自带的 llama.cpp 上

## 适用场景

- U 盘携带，多电脑切换使用
- 断网环境下的本地 AI 助手
- 需要长期记忆的持续对话
- 个人知识库管理
- AI 技能开发和测试
