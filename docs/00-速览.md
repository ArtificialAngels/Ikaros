## 三个端口的职责(防止混淆)

| Port | 进程 | 角色 |
|------|------|------|
| **8080** | llama-server | LLM 推理引擎。OpenAI 兼容 HTTP API。**内部端口** — 不直接对浏览器。 |
| **7860** | Hermes FastAPI (bridge) | embeddings、RAG 检索、sessions / kanban / crons / workspace 等内部 API。**不直接打开浏览器**。 |
| **8648** | Hermes Web UI | **主入口**。Vue 3 SPA + Koa BFF + Socket.IO。浏览器打开 `http://localhost:8648/`。 |

## 一句话总结

**便携 Python** + **llama.cpp router 模式** + **云端 LLM 路由** + **自描述模块化服务** + **完整 Web UI** = 装 U 盘里插哪都能跑的赛博游民数字管家。
