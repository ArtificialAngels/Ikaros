# 00 — 速览

| 项 | 值 |
|---|---|
| 项目名 | **Hermes Agent** |
| 口号 | 赛博游民数字管家 |
| 内核版本 | 2.0.0 |
| Python | 3.12（便携嵌入式，在 `portable-python/` 下） |
| 推理引擎 | llama.cpp（`runtime/` 下） |
| Web 框架 | FastAPI + 内置 Chat Studio |
| Web UI 端口 | `http://localhost:7860` |
| LLM 服务端口 | `http://localhost:8080`（OpenAI 兼容） |
| 本地模型 | Qwen2.5-3B / 7B GGUF |
| 云端支持 | OpenAI / Anthropic / OpenRouter / MiniMax |
| LLM 路由 | fallback_chain（云端优先，故障切本地） |
| 记忆系统 | 长期记忆 + 标签检索 |
| 知识库 | 文档分块 + 向量检索 |
| 技能系统 | 可扩展自定义技能 |
| 启动器 | `launcher.bat`（Tkinter GUI 模型选择器） |
| 诊断工具 | `bin\hermes-doctor.bat`（matsu 风格） |
| 自检工具 | `bin\hermes-firstrun.bat`（GPU 检测 + 环境自愈） |
| 默认配置 | 云端优先、自动 fallback、控制台彩色输出 |

## 一句话总结

**便携 Python** + **llama.cpp 推理引擎** + **云端 LLM 路由** + **记忆/知识/技能** + **内置 Web UI** = 装 U 盘里插哪都能跑的数字管家。
