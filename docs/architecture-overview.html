数据流 一次对话怎么走

1
用户在 dsh web :3080（React + Monaco + terminal + LSP）发起对话或代码任务
2
dsh overlay 注入 v5_* MCP（memory_v5 stdio, 49 工具）+ 持久 PTY 终端 + LSP + Ikaros persona
3
对话树 :48920（独立面板，Explore.poker 卡片图风格）走 ikaros 单模式：注入完整 persona + 树域记忆 → DeepSeek 直连 + 只读工具回路
4
Embedding :8587（bge-m3 Q8_0，1024 维）为 v5 注入与对话树检索提供向量
5
逐轮记忆轻写进 V5（core/memory_v5/data/v5/）；后台 reflect 流水线提炼事实/情感/自我模型
6
V5 经 memory_api / v5_* MCP 工具 暴露检索（dsh web + 对话树共享）
7
Herdr 命名管道为 dsh terminal / tool-terminal 提供持久的 PTY 会话（无 TCP 端口）

边界与约定 关键架构决策

✅ dsh 零源码侵入： 所有 Ikaros 定制走 core/ikaros-dsh/cordis.patch.yml overlay，runtime/dsh/ 始终是上游原版，可独立升级。
✅ v5.db / v5_* 契约保留： 包已重命名 v5→memory_v5，但 DB 文件名 v5.db 与 40 个 v5_* MCP 工具名是对外契约，不改。
✅ IKAROS_ROOT 自锚定： bin/ikaros-env.sh/.bat 自锚定项目根目录（BASH_SOURCE[0] / %~dp0），项目整体移动仍正确；无任何硬编码盘符。
⚠️ E:\v5-memory 独立仓库： 从 core/memory_v5 抽离的开源插件版（无运行数据），两份手动同步，改主工程不影响开源版。
⚠️ 本地 LLM :8080 已退役： 2026-08-18 起 model_config.json initial_model=""（禁用）；按需恢复 = 放 gguf + 设模型名（详见 AGENTS.md）。
