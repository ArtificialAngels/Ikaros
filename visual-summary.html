启动时间线

// BOOT.SEQUENCE

T+0s

插入移动硬盘

系统识别为可移动磁盘。USB 3.2+ 推荐（NVMe 协议 SSD 移动硬盘更佳）。第一次插需要 5-10 秒挂载。

T+5s

双击 start.bat / 执行 ./scripts/start.sh

启动脚本自动解析 U 盘根目录（不依赖固定盘符），检测 Podman/Docker，缺失时给出安装指引。

T+10s (首次) / T+1s (后续)

镜像加载

首次：gunzip -c image.tar.gz | docker load（USB 3.2 上 1.5GB ≈ 60-90 秒）。后续：秒级，镜像已缓存在宿主机。

T+90s (首次) / T+5s (后续)

容器启动

以 --rm 模式启动，--read-only 根文件系统，--cap-drop=ALL 丢掉所有权限。tini 作为 PID 1 正确处理信号。

T+95s

Hermes 就绪

访问 http://localhost:7860 即可看到 Web UI。配置 / 记忆 / 技能全部从 U 盘 bind mount 进来，所有写入都回 U 盘。

退出

过境无痕

Ctrl+C → tini 收到 SIGTERM → entrypoint 优雅退出 → --rm 触发容器销毁 → 宿主机文件系统零残留（除了 Docker 镜像缓存）。

核心 Docker 命令

// KEY.COMMANDS

构建 + 导出镜像

# 构建（多平台可选）
docker buildx build --platform linux/amd64 \
    --output type=docker,dest=image.tar \
    -t portable-hermes:latest .

# 压缩保存到 U 盘
docker save portable-hermes:latest | gzip -9 > image.tar.gz

# 验证大小（应该 700MB-1.2GB）
ls -lh image.tar.gz

启动容器（极简版）

docker run -it --rm \
    --name hermes-portable \
    --user 1000:1000 \
    -v "$PWD/data:/data" \
    --read-only \
    --cap-drop=ALL \
    -p 7860:7860 \
    portable-hermes:latest

过境无痕加固版

docker run -it --rm \
    --name hermes-portable \
    --user 1000:1000 \
    -v "$PWD/data:/data" \
    -v "$PWD/data/cache/tmp:/tmp" \
    --tmpfs /run:size=8m \
    --read-only \
    --cap-drop=ALL \
    --security-opt=no-new-privileges \
    --pids-limit 100 \
    --memory 4g \
    -p 7860:7860 \
    portable-hermes:latest

--cpus 限制 --memory 限制 network=host 可选 skip GPU
