Ikaros 控制台 · 快速上手

四个要点，一分钟学会

1

启停组件

每张组件卡都有「启动 / 停止 / 重启」按钮，顶部可一键启动或停止全部。绿点 = 运行中，红点 = 已停止。

2

自由布局

按住卡片标题栏可拖动，边缘和角落可缩放。拖动时自动吸附对齐，布局会记忆到本地。

3

实时监控

情感 (PAD)、生命活力、自我思考、V5 记忆、事件流——右侧仪表带实时刷新，展示伊卡洛斯的内部状态。

4

主题与恢复

右上角切换深色 / 浅色主题。想恢复初始布局点「重置布局」，随时可重新打开本引导。
